# HandyMan Product Vision

## Proposition

HandyMan helps people find beautiful DIY projects and actually build them.

Rather than stopping at inspiration, each project connects the finished object to the information needed in the workshop: materials, tools, dimensions, drawings, patterns and sequenced instructions.

## Initial information architecture

### Discover
Curated project feed, categories, search and filters.

### Project
Overview, result, difficulty, time, cost and required tools.

### Build
Materials, cut list, technical plan and step-by-step instructions.

### My Projects
Saved projects, build progress and completed work.

### Profile
Preferences, units and later creator/account capabilities.

## Initial categories

- Furniture
- Storage
- Home decor
- Outdoor
- Workshop
- Small builds
- Beginner projects
- Joinery / skills

## North-star experience

A user should be able to see a project, understand whether it is realistic for them, gather everything they need and start building without hunting across unrelated pages.
